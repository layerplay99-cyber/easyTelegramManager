# 后台使用帮助（业务人员上手指南）

> 面向业务 / 运营人员，介绍后台每个功能页面的用途、字段和操作，按后台侧边栏菜单组织。
> 本文档与后台「使用帮助」菜单内容一致。

## 一、后台菜单地图

| 菜单 | 页面 | 用途 |
|---|---|---|
| 号码采集 | 号码仓库 / 扫描记录 / 账号仓库 | 手机号采集与扫描结果、真人号账号 |
| 附加功能 | 功能列表 / 三方配置 / 三方接口 / 上游接口配置 | 功能编排与三方上游接入 |
| 机器人管理 | Telegram 客服 / 机器人列表 / 群分组 / 群列表 | 机器人、群及其配置 |
| 钱包管理 | 会员 / 钱包 / 充值订单 / 提现订单 / 账本流水 / 支付通道 / 风控中心 / 交易限额 / 汇率 | 钱包收付款全链路 |
| 平台管理 | 商户管理 | 平台商户（租户），数据隔离单位 |

## 二、快速上手（后台操作流程）

### 流程 1：接入第一个机器人并让功能跑起来

1. 「机器人管理 → 机器人列表」新增，填 Api_Token、Bot 用户名、Url_Token；「Webhook 指向」选「当前平台」自动填地址。
2. 打开该机器人「激活」开关，系统自动设置 webhook（关闭则卸载）。
3. 把机器人拉进目标群后，到「群列表」同步出群。
4. 「功能列表」建功能（或直接用已有），再给机器人「功能配置」分配功能、给群「功能」挑选功能（群只能从机器人已分配的功能里选）。

### 流程 2：接入一个三方上游（回调 + 接口）

1. 「三方配置」新增，填名称、api 地址、token、公钥、密钥（`secrept_key`，我方调上游的出站凭证）。
2. 点「生成密钥」拿到 `access_key` / `secret_key`（明文只显示一次）发给上游，用于上游回调我方时验签。
3. 「三方接口」是平台接口只读清单（代码同步，不可手工增删）。
4. 「上游接口配置」选该上游，按需覆盖接口路径 / 方法（留空回退平台默认）。
5. 「功能列表」建功能并在配置里选「承接上游」；回调类功能再进「回调设置」配路由表、机器人、群。

### 流程 3：配置钱包收付款

1. 「支付通道」配充值 / 提现通道（类型、币种、费率、单笔 / 每日限额、API、密钥）。
2. 「交易限额」按会员等级 + 币种配单笔 / 日 / 月限额。
3. 「汇率」维护货币对基准价、买入 / 卖出价。
4. 「风控中心」配规则（场景、动作、触发条件）。
5. 会员在群里 `/cz` `/tx`，后台在「充值订单」「提现订单」审核处理，在「账本流水」对账。

### 流程 4：真人号采集 / 客服

1. 「账号仓库」（或「Telegram 客服」）新增，填 APP ID、APP Hash、手机号。
2. 点「登录」扫码 / 验证码 / 2FA 完成登录。
3. 点「同步群」拉取该账号名下群。
4. 点「功能」给账号分配真人功能（群发、私发等）。

### 流程 5：号码采集

1. 「号码仓库」下载模板 → 填号码 → 导入（支持 xlsx/xls，异步导入有进度），也可手动新增。
2. 「扫描记录」查看各号码扫描结果（N 天内活跃、用户名、简介、头像）。

## 三、后台功能说明（按菜单）

### 1. 号码采集

**号码仓库** — 存放采集到的手机号。
- 字段：`手机号`。
- 操作：新增 / 编辑 / 删除、导入（异步进度）、导出、下载模板。

**扫描记录** — 记录对某号码的扫描结果。
- 字段：被扫电话、N 天内活跃、用户名、简介、用户头像。
- 操作：新增 / 编辑 / 删除（纯记录）。

**账号仓库** — 维护用于真人采集 / 客服的 Telegram 账号。
- 字段：APP ID、APP Hash、电话号码、昵称、状态（启用 / 禁用）。
- 列表列：登录状态（已登录 / 未登录 / 等待验证 / 登录过期 / 等待登录完成）、入群数。
- 操作：登录 / 注销（扫码、验证码、2FA 弹窗）、功能（分配真人功能）、同步群、导入 / 导出。
- 说明：与「机器人管理 → Telegram 客服」是同一页面；同步的群会进「群列表」。

### 2. 附加功能

**功能列表** — 管理机器人 / 真人可执行的功能。
- 字段：功能名称、执行器（选定后动态渲染配置表单）、触发方式（斜杠命令 / 消息 / 按钮回调 / 三方推送 / 手动接口 等）、功能分类、描述、是否启用、命令配置（命令名 / 描述 / 用法 / 参数）。
- 操作：启用开关；`接收三方推送` 类型显示「回调设置」入口。
- 回调设置字段：回调地址（只读复制）、幂等去重字段、消息处理（转换器）、默认机器人、路由字段、兜底群、路由表（商户 ID → 机器人 + 群）。

**三方配置** — 维护「我方 → 上游」的接入配置与入站密钥对。
- 字段：接口名称、api、token、公钥、密钥（`secrept_key` 出站凭证）。
- 列表列：接入标识、密钥状态（未生成 / 已启用 / 已吊销）、归属商户。
- 操作：生成密钥（明文只显示一次）、吊销密钥、接口配置（跳转上游接口配置）、编辑时绑定功能。

**三方接口** — 平台接口只读清单 + 默认值管理。
- 字段：接口标识 / 名称 / 方法 / 路径模板（只读）、超时、启用、请求头、固定参数、备注。
- 操作：仅编辑（接口由功能代码声明并同步，不能新增 / 删除）。

**上游接口配置** — 为「每个上游 + 平台接口」单独配置实际请求路径 / 方法。
- 字段：每行路径（支持 `{参数名}` 占位、绝对 URL，留空回退平台默认）、方法、启用、备注。
- 操作：顶部选「上游配置」→ 表格逐行覆盖 → 保存（整批替换）。只显示该上游已绑定功能用到的接口。

### 3. 机器人管理

**机器人列表** — 维护 Bot，激活 webhook、群发、配功能与上游。
- 字段：Api_Token、Bot 用户名、Url_Token、Webhook 指向（平台 / 自定义外链）、WebHookUrl、默认上游（仅超管）、描述。
- 操作：激活 / 关闭开关、查看状态（webhook 地址、错误、积压数）、群发（bot / user 通道 + 进度）、功能配置、配置上游。

**群分组** — 给群分类，方便批量群发 / 管理。
- 字段：分组名称、分组描述。
- 操作：新增 / 编辑 / 删除（删除自动解绑关联群的 `group_id`）。

**群列表** — 管理同步上来的群。
- 编辑字段：语种（默认中文）、商户 ID（该群默认商户号，留空取 `/bd` 绑定）、进群欢迎语（支持 username / full_name 占位，按群语种翻译）、自动回复（关键词 + 回复，可多条）。
- 操作：编辑、功能（从机器人已分配功能里选）、删除（清理关联）、批量设置分组。

### 4. 钱包管理

**会员** — 管理钱包会员（TG 用户），查看钱包、冻结 / 解冻。
- 列表列：TG 用户 ID、用户名、状态（正常 / 冻结 / 禁用）、支付密码、最后活跃、注册时间。
- 操作：查看钱包（各币种可用 / 冻结余额、累计充值 / 提现）、冻结 / 解冻、重置支付密码。

**钱包** — 管理每个会员分币种的钱包账户，支持人工调账和启停。
- 列表列：会员 ID、币种、可用余额、冻结余额、累计充值、累计提现、状态。
- 操作：调整余额（奖励加钱 / 扣款减钱，事由必填，写流水）、启用 / 禁用、开户。

**充值订单** — 查看和管理充值订单，手工补单 / 取消。
- 列表列：订单号、会员 ID、币种、金额、到账、上游、状态（待支付 / 已支付 / 已完成 / 已取消 / 已超时 / 失败）。
- 操作：完成（仅待支付 / 已支付）、取消（仅待支付）。

**提现订单** — 查看和管理提现订单。
- 列表列：订单号、会员 ID、币种、金额、实付、上游、状态（待处理 / 处理中 / 已完成 / 已取消 / 失败）。
- 操作：处理中（仅待处理）、完成（扣除冻结余额）、取消（解冻余额）、批量处理。

**账本流水** — 只读查看所有资金变动流水。
- 列表列：会员、类型（充值 / 提现 / 冻结 / 解冻 / 奖励 / 扣款 / 转入 / 转出 / 调账）、币种、变动、变动前 / 后余额、关联单号、时间。
- 操作：无（只读，由钱包加减款 / 冻结解冻自动写入）。

**支付通道** — 配置充值 / 提现可用通道及其费率、限额、API、密钥。
- 字段：通道名称、编码、类型（充值 / 提现 / 充值+提现）、币种、支付方式、提单 API、查单 API、费率、固定手续费、单笔最小 / 最大、每日限额、每日笔数、商户号、密钥、状态。
- 操作：启用 / 禁用 / 维护切换。

**风控中心** — 配置风控规则并处理风控日志（Tab：风控规则 / 风控日志）。
- 规则字段：规则名称、编码、场景（充值 / 提现 / 转账）、动作（拒绝 / 人工审核 / 冻结 / 通知）、风险等级、优先级、触发条件（JSON）、状态。
- 日志操作：标记处理 / 忽略。

**交易限额** — 按等级 / 币种配置充值、提现的单笔、日、月限额。
- 字段：类型（充值 / 提现）、等级、币种、单笔最小 / 最大、日 / 月累计额、日 / 月笔数、状态。
- 操作：启用 / 禁用。

**汇率** — 维护货币对汇率。
- 字段：源币种、目标币种、基准汇率、买入价、卖出价、来源（manual / api）、自动更新、状态。
- 操作：增删改（供余额换算 / 下单计算使用）。

### 5. 平台管理

**商户管理** — 维护平台商户（租户），数据隔离单位，仅平台超管可访问。
- 字段：商户名称（必填）、商户短码（必填、唯一、仅字母数字下划线短横线）、联系人、状态（启用 / 禁用）。
- 操作：新增 / 编辑 / 删除（名下有业务数据则拒绝删除）；新建后刷新顶栏「归属商户」下拉。
