下载与安装

安装器会从本站拉取对应版本的安装包，校验后解压部署。目标机只需要 Docker 与 compose 插件， 不需要 git、Node，也不需要预装 PHP / MySQL。

一键安装

把 tg.example.com 换成你的域名；域名需要提前解析到这台服务器。

在目标服务器上执行（root）
# 下载安装器 curl -fsSL __ORIGIN__/install.sh -o /tmp/easytg.sh # 安装（--domain 必填；默认装到 /opt/easytg） sudo bash /tmp/easytg.sh --domain tg.example.com # 想先看看它会做什么，不落任何文件： sudo bash /tmp/easytg.sh --domain tg.example.com --dry-run
curl -fsSL __ORIGIN__/install.sh -o /tmp/easytg.sh && sudo bash /tmp/easytg.sh --domain tg.example.com
缺 Docker？加 --install-docker，安装器会用官方脚本装 Docker（Debian / Ubuntu）。 已有 Docker 的机器忽略此参数。

安装参数

全部可选，也可用同名环境变量（如 TG_DOMAIN=）覆盖。

参数默认值说明
--domain无（必填）后台访问域名，写入 Nginx 与前端配置
--dir/opt/easytg安装目录，安装包解压到这里
--versionlatest安装版本，对应下载站的发布包
--port80HTTP 端口；启用 --ssl 时再监听 443
--ssl关闭启用 HTTPS（证书放 /etc/nginx/ssl/<域名>/）
--package无离线安装：指定本地 zip 包，跳过下载
--install-docker关闭缺 Docker 时自动安装
--dry-run关闭只打印将要执行的步骤

安装后

安装器结束时会打印访问地址。首次登录请改密码。

登录后台

初始账号 catchadmin / 密码 catchadmin。

建机器人

填 BotFather 拿到的 token，激活后用「查看状态」确认连通。

绑群 + 挑功能

把机器人拉进群 → 后台绑定群 → 在功能列表勾选并配置命令。

接上游（可选）

三方配置填上游地址与密钥，选定适配器；字段映射写在该厂商适配器里。

日常运维
# 查看容器状态 cd /opt/easytg && docker compose ps # 拉新版本并重建（保留数据） sudo bash /opt/easytg/install.sh --update # 看 PHP 日志 docker compose logs -f php # 停止 / 卸载（数据卷保留） docker compose down

常见问题

服务器最低配置？

2 核 2G 起步，40G 磁盘。识图 / 真人号（Telethon）会额外吃内存，建议 2 核 4G。

能装在内网 / 无外网吗？

可以。把发布包与安装器拷到机器上，用 --package /path/xxx.zip 离线安装； 首次启动不额外下载依赖。

会不会覆盖已有数据？

安装器只在空目录初始化；升级用 --update，只更新代码并跑增量迁移，数据库与媒体卷不动。

和已有 Nginx 冲突吗？

默认自包含一套 Nginx。想复用宿主反代，用 --port 换端口后自行转发 80/443。
