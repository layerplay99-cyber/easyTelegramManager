一条命令装完

目标机只需要 Docker（含 compose 插件）。安装包从本站拉取，全程不需要 git、不需要 Node。

bash · root
# 1. 下载安装器 curl -fsSL __ORIGIN__/install.sh -o /tmp/easytg.sh # 2. 指定域名安装（自动拉包、起容器、跑迁移） sudo bash /tmp/easytg.sh --domain tg.example.com ✔ 后台地址 https://tg.example.com

检查环境

Docker / compose 版本、磁盘空间、端口占用；缺 Docker 可加 --install-docker 自动装。

拉包并生成配置

下载对应版本安装包，校验 SHA256，解压到安装目录，按域名生成配置与随机密钥。

起容器并初始化

MySQL / Redis / PHP / Nginx 全套自包含，等数据库就绪后自动建表、写入初始数据。

打开后台

初始账号 catchadmin / catchadmin，登录后请立刻改密码。

需要单独的反代、已有共享 Nginx、或离线内网安装？完整参数见 下载页。
