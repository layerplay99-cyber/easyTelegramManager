# 使用帮助（业务人员上手指南）

> 面向业务 / 运营人员。按「快速上手」照做即可，各入口的字段说明见「功能说明」。
> 本文档与后台「使用帮助」菜单内容一致。

## 快速上手（操作流程）

### ① 接入三方上游回调：让交易通知自动发到群里

1. 「三方配置」新建上游，点「生成密钥」，把 `access_key` / `secret_key` 发给上游（`secret_key` 只显示一次，请当场保存）。
2. 「功能列表」新建功能，执行器选「接收三方推送」（通用）或「[示例]交易通知」。
3. 配置「回调设置」：填默认机器人、路由字段（如 `merchant_id`）、兜底群，拿到回调地址 `/api/hooks/{token}`。
4. 群里发 `/bd 商户号`，把群和商户号绑到一起。
5. 上游带签名头回调，验签通过后群里收到通知（回调需带 `X-Access-Key` / `X-Timestamp` / `X-Nonce` / `X-Signature` 四个请求头）。

### ② 配置群内「确认 / 驳回」按钮

1. 回调功能执行器选「交易通知 → 群内按钮」，在「回调设置 → 消息处理」里按需转换上游字段。
2. 新建「交互按钮点击处理」功能，绑定同一机器人 + 同一群，在 branches 里配「确认 / 驳回」各自的行为。
3. 群里发 `/trsq 用户ID|@用户名`，指定谁能点按钮。
4. 上游回调 → 群里出现按钮 → 指定人点击 → 结果提交上游。

### ③ 钱包充值 / 提现

1. 群里发 `/cz 金额` 充值，机器人返回支付链接，支付完成后回调入账。
2. `/yue` 查余额、`/zd` 查账单流水。
3. `/tx 金额` 提现：提交后冻结余额，由上游代付，到账后扣减。
4. 支付通道、交易限额、风控、汇率在后台「钱包管理」目录下统一配置。

### ④ 机器人 + 群 + 功能绑定（基础配置）

1. 「机器人列表」添加机器人（填 `api_token`）。
2. 「群列表」同步群（先把机器人拉进群）。
3. 「功能列表」把功能绑定到机器人 + 群（一个功能可绑定多个群，群只能用机器人已分配的功能）。

### ⑤ 真人号群发 / 私发

1. 准备「真人账号操作」类型的账号。
2. 新建功能并选对应执行器（消息群发 / 私发 / @发送 / 踢人 / 快捷回复等），绑定目标群。
3. 触发后按配置发送。

## 功能说明

### 一、三方回调类（第三方主动推送）

| 功能 | 触发方式 | 说明 |
|---|---|---|
| 接收三方推送 | 上游 POST 回调 | 通用回调入口，把上游推送转成群消息，入站统一走 `X-Access-Key` 头签名验签 |
| 交易通知 → 群内按钮 | 上游 POST 回调 | 回调转成带「确认 / 驳回」按钮的消息，配合「交互按钮点击处理」使用 |
| 交互按钮点击处理 | 用户点按钮 | 处理按钮点击，按 branches 执行确认 / 驳回分支 |

### 二、商户命令（群里发斜杠命令）

| 命令 | 说明 |
|---|---|
| `/bd 商户号` | 绑定 / 查看本群商户号 |
| `/cx 订单ID` | 查询代收 / 代付订单详情 |
| `/xe 金额` | 设置代付订单二次确认限额（0 取消） |
| `/xq` | 查询当前代付二次确认限额 |
| `/trsq 用户ID|@用户名` | 设置可点击交易按钮的人（clear 恢复默认） |
| `/yj 金额` | 设置余额不足提醒的预警金额 |
| `/ye` | 查询当前群绑定商户的余额 |

### 三、钱包命令（群里发斜杠命令）

| 命令 | 说明 |
|---|---|
| `/yue` | 查询钱包余额 |
| `/zd` | 查询我的账单流水 |
| `/cz 金额` | 充值（返回支付链接） |
| `/tx 金额` | 提现（冻结余额，上游代付） |

### 四、识图

| 功能 | 触发方式 | 说明 |
|---|---|---|
| 识图（OCR 提取文字） | 群里发图片 | 识别图片里的文字并回复到群里 |

### 五、真人号功能

| 功能 | 说明 |
|---|---|
| 消息私发 / 群发 | 用真人号向单个用户或目标群发送消息 |
| @发送 / 踢人 | 在群里 @某人 或把人移出群 |
| 快捷回复 | 命中关键词时自动回复预设内容 |
| 表情包采集 | 采集群内表情包素材 |

### 六、其他执行器

| 执行器 | 说明 |
|---|---|
| 调用三方接口 | 按平台接口规范调上游接口（查询余额、下单等） |
| 绑定 / 保存数据 | 把用户发来的数据保存下来 |
| Mini App | Telegram Mini App 相关能力 |
