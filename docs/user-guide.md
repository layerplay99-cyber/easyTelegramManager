# 平台使用帮助

> 面向业务 / 运营人员。全文只讲**怎么操作**：去哪个菜单、点哪个按钮、填什么、做完怎么验证。
> 与后台「使用帮助」菜单内容一致。

---

## 一、快速上手：从零跑通第一个群

按顺序做完 8 步，机器人就能在群里响应命令、接收上游通知。每步的「验证」一定要确认再往下走。

### 第 1 步 · 确认归属商户

**目标**：让后续建的机器人、三方配置都挂在正确的商户下（平台超管才需要做）。

1. 打开「平台管理 → 商户管理」，看列表里是否已有本次要用的商户。已有就跳过本步；没有则点左上角「新增」。
2. 填「商户名称」「商户短码」，点「确定」。商户短码只能用字母、数字、下划线、短横线，且不能重复；「状态」保持启用。
3. 回到页面顶部，在「归属商户」下拉里选中刚建的商户。之后新建的机器人、三方配置都会归到这个商户，其他商户看不到。

> **验证**：顶部「归属商户」显示的商户名和你要用的一致。

### 第 2 步 · 添加机器人

**目标**：把 BotFather 给的机器人登记到平台，并把 webhook 地址配好。

1. 打开「机器人管理 → 机器人列表」，点左上角「新增」。
2. 填「Api_Token」——粘贴 BotFather 给你的 token，形如 `123456:ABC-DEF...`。
3. 填「Bot 用户名」「Url-Token」。Url-Token 自己定一串随机字符串，用于 webhook 地址校验，不要和其他机器人重复。
4. 「Webhook 指向」选「当前平台」。选好后「WebHookUrl」会自动填成 `你的域名/api/webhook/pull`，不用手改。
   - 只有要转发到外部系统时才选「自定义外链」并手填地址。
5. 填「Bot 描述」（选填），点「确定」。此时「激活状态」是关的，属正常。

> **验证**：列表里能看到这个机器人，Api_Token、Bot 用户名都和填写一致。

### 第 3 步 · 激活机器人

**这一步不做，机器人收不到任何消息。**

1. 在「机器人列表」找到刚建的那行，打开「激活状态」开关。开关变亮即触发注册，稍等 1~2 秒。
2. 点同一行的「查看状态」，弹窗里会显示 webhook 注册地址、最后错误信息、积压更新数。
3. 确认「webhook 地址」有值、「最后错误信息」为空、「积压更新数」为 0。若地址为空或有错误，先关闭「激活状态」再重新打开一次；仍不行就检查 Api_Token 是否填错、域名 Telegram 能否访问。
   - 机器人停用或换域名后，也要重新开关一次激活。

> **验证**：「查看状态」里 webhook 地址有值且无错误，说明平台已能收到 Telegram 推送。

### 第 4 步 · 让机器人进群并同步出群

1. 在 Telegram 客户端里把这个机器人拉进目标群（机器人需要有读消息权限）。
2. 在群里随便发一条消息（例如 `/start`）。机器人靠收到消息来感知群，不发消息后台可能暂时看不到这个群。
3. 打开「机器人管理 → 群列表」，点搜索 / 刷新，找到刚进的群，列表会显示「群名称」「群聊ID」「botId」。
   - 用真人号采集的群，走「号码采集 → 账号仓库 → 同步群」拉取。

> **验证**：「群列表」里能看到这个群，且群名称和 Telegram 里一致。

### 第 5 步 · 配置群（语种、商户号、欢迎语）

1. 在「群列表」找到该群，点「编辑」，打开配置弹窗（群名称、群聊ID 只读）。
2. 「语种配置」选这个群要用的语言。群里所有自动回复、提示都按这个语种出，默认中文。
3. 「商户ID」填该群对应的商户号。填了之后这个群的业务数据都归该商户；留空则以后在群里用 `/bd 商户号` 绑定。
4. 按需填「进群欢迎语」和「自动回复」。欢迎语支持 `username`、`full_name` 占位；自动回复按「关键词 + 回复内容」成对添加，可加多条。
5. 点「确定」。

> **验证**：重新点开「编辑」，刚才填的语种、商户ID 都还在。

### 第 6 步 · 给机器人和群分配功能

1. 打开「附加功能 → 功能列表」，确认需要的功能已「启用」（列表右侧开关）。没启用的功能不会响应。要新建功能就点「新增」，选好「执行器」和「触发方式」后点「确定」。
2. 打开「机器人管理 → 机器人列表」，点该行的「功能配置」，勾选这个机器人允许使用的功能，点保存。**这是机器人级白名单，不勾的话群里选不到。**
3. 打开「机器人管理 → 群列表」，点该群的「功能」，从「机器人已分配的功能」里挑这个群要用的，点保存。

> **验证**：再点开群的「功能」，能看到已勾选的功能。

### 第 7 步 · 在群里验证

1. 在 Telegram 群里发一条已分配功能对应的命令，例如 `/yue`，等 1~2 秒看机器人是否回复。
2. 没回复时按顺序排查：① 机器人「激活状态」是否打开；② 「查看状态」里有无 webhook 错误；③ 功能列表里该功能是否启用；④ 机器人「功能配置」和群「功能」是否都勾了；⑤ 群「语种配置」是否选对。
3. 需要商户数据的命令（如 `/ye`、`/cx`）先在群里发 `/bd 商户号` 把群和商户号绑定。

> **验证**：机器人能在群里正常回复，说明主链路已跑通。

### 第 8 步 · 接入三方上游（需要上游回调 / 查接口时才做）

1. 打开「附加功能 → 三方配置」，点「新增」，填「接口名称」「api」「token」「公钥」「密钥」，点「确定」。
   - 这里的「密钥」是我方调上游用的出站凭证（secrept_key），和下面生成的入站密钥不是一回事。
2. 在列表点该行的「编辑」，在「绑定功能」里勾选要用这个上游的功能，点「保存」。只列需要交互上游的功能；绑定后「上游接口配置」才会显示对应接口。
3. 同一个编辑弹窗里点「生成密钥」，**立刻复制并保存** `access_key` 和 `secret_key`。弹窗同时给出 headers、canonical、signature 规范，一并发给上游开发。
   - 明文只显示这一次，关掉就再也看不到，只能重新生成（会让上游旧密钥失效）。
4. 点该行「接口配置」，会跳到「上游接口配置」并自动选中该上游。逐行按上游实际文档改「该上游路径」「方法」，看右侧「实际请求地址」预览是否正确，点「保存」。
   - 路径留空就回退用平台默认；支持 `{参数名}` 占位，也可以直接填绝对 URL。
5. 到「功能列表」找到「接收三方推送」类的功能，点「回调设置」，复制「回调地址」给上游，在「路由表」里加好「商户ID → 机器人 + 群」的映射并保存。
6. 让上游按规范带四个请求头回调：`X-Access-Key` / `X-Timestamp` / `X-Nonce` / `X-Signature`。验签通过后按路由表把消息发到对应群。

> **验证**：让上游发一条测试回调，目标群能收到消息；收不到就检查「回调设置」里的路由表是否配了对应商户ID。

## 二、操作指南（按后台菜单）

### 号码采集

#### 号码仓库

**批量导入一批手机号**
1. 点「下载模板」，得到一个 Excel 模板。
2. 按模板第一列填手机号，保存为 xlsx / xls。
3. 点「导入」，选择文件并确认上传；导入是后台异步执行，页面会显示进度。
4. 进度到 100% 后点查询 / 刷新，列表里能看到导入的号码。

**单独加一个号码 / 改错**
1. 点左上角「新增」，填「手机号」，点「确定」。
2. 改号就点该行「编辑」，改完点「确定」；不要用的点「删除」。

**导出**：点「导出」，下载当前数据的 Excel。

#### 扫描记录

**登记一条扫描结果**
1. 点「新增」，依次填「被扫电话」「N天内活跃」「用户名」「简介」「用户头像」。
2. 点「确定」保存；之后可在列表里「编辑」或「删除」。

#### 账号仓库（同「机器人管理 → Telegram 客服」）

**新增一个真人号账号**
1. 点「新增」，填「APP ID」「APP Hash」「电话号码」「昵称」，「状态」选启用，点「确定」。
2. APP ID / APP Hash 在 Telegram 开发者后台申请，一个手机号对应一套。

**登录账号**
1. 点该行「登录」，按弹窗提示完成扫码 / 输入验证码；开了两步验证的再填 2FA 密码。
2. 看列表「登录状态」变成「已登录」才算成功；显示「等待验证」就回到弹窗继续。
3. 掉线时状态会变「登录过期」，重新点「登录」即可；不用了点「注销」。

**把账号的群同步到平台**
1. 点该行「同步群」，等待拉取完成。
2. 打开「机器人管理 → 群列表」，确认这些群已出现。

**给账号分配真人功能**
1. 点该行「功能」，勾选要用的真人功能（群发、私发等），保存。
2. 列表行上会出现已绑定功能按钮，点它、选目标群即可直接执行一次。

**批量加账号**：点「导入」上传 xls/xlsx/csv；需要底表就先点「导出」。

### 附加功能

#### 功能列表

**新建一个功能**
1. 点「新增」，填「功能名称」，在「执行器」下拉里选类型。
2. 选好执行器后，下方会自动出现该执行器专属的配置表单，按需要填。
3. 选「触发方式」：群里发命令选「斜杠命令」、上游推送选「三方推送」、点按钮选「按钮回调」。
4. 选「功能分类」、填「功能描述」，点「确定」。
5. 回到列表，把新功能右侧的「启用」开关打开；不开不会生效。

**给功能配群命令**
1. 点该行「编辑」，在命令配置区填「命令名」（不带斜杠）、「命令描述」、「用法示例」。
2. 命令需要参数就点「新增字段」，填参数名、说明、正则、是否必填。
3. 点「确定」保存；列表「命令」列会出现 `/命令名` 标签。

**配回调地址与路由表**（只有「接收三方推送」类功能有此按钮）
1. 在列表找到该行，点「回调设置」。
2. 复制弹窗里的「回调地址」，发给上游作为推送目标。
3. 填「幂等去重字段」（一般填上游单号字段，防止重复推送刷群）、「路由字段」（如 `merchant_id`）。
4. 选「默认机器人」、填「兜底群」，用于消息找不到对应商户时的兜底。
5. 在「路由表」点新增，逐行填「商户ID / 路由键值」+ 对应「机器人」+「群」+ 备注，打开启用。
6. 点「保存」。之后上游推来的数据按这个映射发到对应群。

**临时停用某功能**：直接在列表把该行「启用」开关关掉，不用删除，随时可以再打开。

#### 三方配置

**新建一个上游**
1. 点「新增」，填「接口名称」「api」「token」「公钥」「密钥」，点「确定」。
2. 这里的「密钥」是我方调上游接口的出站凭证，向上游要；不要和「生成密钥」混用。
3. 「归属商户」是只读的，由顶部「归属商户」下拉决定，选错了先去顶部换商户再回来建。

**绑定这个上游能支撑哪些功能**
1. 点该行「编辑」，拉到「绑定功能」，多选需要交互上游的功能，点「保存」。
2. 只列「需要上游」的功能；不绑定的话「上游接口配置」里接口列表会是空的。

**生成入站密钥（给上游回调验签用）**
1. 仍在该行「编辑」弹窗里，点「生成密钥」。
2. 弹窗会显示 `access_key`、`secret_key`、headers、canonical、signature，**立刻复制保存**。
3. 把这些信息发给上游开发，让他们按规范带 `X-Access-Key` / `X-Timestamp` / `X-Nonce` / `X-Signature` 四个头回调。
4. 关掉弹窗后明文不再显示；密钥泄露或要轮换，再点一次「生成密钥」即可（旧密钥立即失效，记得通知上游同步更换）。
5. 要彻底停用就点「吊销密钥」。

**去配这个上游的接口地址**：点该行「接口配置」，会跳到「上游接口配置」并自动选中它。

#### 三方接口

**改接口的默认值**
1. 这个列表是代码同步出来的接口清单，不能「新增」「删除」。
2. 点某行「编辑」，只能改「超时」「启用」「请求头」「固定参数」「备注」，点「确定」。
3. 「接口标识 / 名称 / 方法 / 路径模板」是只读的，要改得改代码后让功能重新同步。

#### 上游接口配置

**给某个上游单独改接口路径**
1. 在页面顶部「上游配置」下拉里选中要改的上游（从「三方配置」点「接口配置」进来会自动选好）。
2. 下面表格只列这个上游已绑定功能用到的接口；找到要改的那行，在「该上游路径」里填上游文档给的实际路径。
3. 路径支持 `{参数名}` 占位，也可以直接填完整 URL；留空表示沿用「平台默认路径」。
4. 按需改「方法」、打开 / 关闭「启用」、填「备注」，同时看「实际请求地址」列的实时预览是否正确。
5. 点「保存」，整批生效。

### 机器人管理

#### 机器人列表

**新增并激活机器人**
1. 点「新增」，填「Api_Token」「Bot 用户名」「Url-Token」。
2. 「Webhook 指向」选「当前平台」，「WebHookUrl」会自动填好；「Bot 描述」选填。
3. 点「确定」保存，然后打开该行「激活状态」开关。
4. 点「查看状态」，确认 webhook 地址有值、无最后错误、积压更新数为 0。

**给机器人分配功能 / 上游**
1. 点该行「功能配置」，勾选允许使用的功能，保存（机器人级白名单）。
2. 超管点「配置上游」，多选可用上游并指定「默认上游」，点确定。

**群发消息**
1. 点该行「群发」选具体机器人，或点页面顶部「群发」做全量。
2. 在弹窗里选目标群 / 分组、填消息内容，发送后可查看发送进度。

**排查机器人不回消息**
1. 点「查看状态」看 webhook 地址与最后错误信息。
2. 有错误或地址为空：先关「激活状态」再打开一次，重新注册 webhook。
3. 仍不行：检查 Api_Token 是否填错、域名 Telegram 是否可访问。

#### 群分组

**建一个分组并归群**
1. 点「新增」，填「分组名称」「分组描述」，点「确定」。
2. 到「群列表」勾选多个群，用「批量设置分组」选刚建的分组。

**删分组**：点该行「删除」即可；删掉后原来属于它的群会自动解绑分组，群本身不会被删。

#### 群列表

**配置单个群**
1. 点该行「编辑」，选「语种配置」（决定群里回复用什么语言）。
2. 填「商户ID」（留空则由群内 `/bd 商户号` 决定）。
3. 填「进群欢迎语」，可用 `username`、`full_name` 占位；需要自动回答复选「自动回复」，按「关键词 + 回复内容」加多条。
4. 点「确定」，再打开编辑确认内容已保存。

**给群挑功能**
1. 点该行「功能」，从「该群所属机器人已分配的功能」里勾选，保存。
2. 这里选不到某个功能时，先去「机器人列表 → 功能配置」把功能加给机器人。

**批量移动群到某分组**：勾选多个群的复选框，点「批量设置分组」，选目标分组。

**删除群**：点该行「删除」；会同时清理该群的语种配置、商户绑定等关联数据，不可恢复。

### 钱包管理

#### 会员

**查某会员的资金情况**
1. 在列表按 TG用户ID / 用户名找到该会员，点「查看钱包」。
2. 弹窗按币种列出「可用余额」「冻结余额」「累计充值」「累计提现」。

**冻结 / 解冻会员**
1. 点该行「冻结」立即限制该会员交易；恢复点「解冻」。
2. 会员忘记支付密码时点「重置支付密码」。

#### 钱包

**人工给会员调账**
1. 在列表找到「会员ID + 币种」对应的那行，点「调整余额」。
2. 选「类型」：奖励（加钱）/ 扣款（减钱），填「金额」，**「事由」必填**，备注选填。
3. 点确定；完成后到「账本流水」能查到这条调账记录（系统自动写流水）。

**停用某个钱包**：点该行「启用/禁用」切换状态；禁用后该币种账户不能交易。

#### 充值订单

**手工补单（钱到了但订单没完成）**
1. 按订单号找到订单，确认「状态」是「待支付」或「已支付」。
2. 点「完成」，系统会补记账、增加会员钱包余额并写流水。

**取消一笔充值**：仅「待支付」订单可点「取消」；已支付 / 已完成的不能在这里取消。

**核对到账**：看「金额」与「到账」是否一致，「上游」列显示走的是哪个上游，异常时按订单号找上游对账。

#### 提现订单

**处理一笔提现**
1. 「待处理」订单点「处理中」，表示上游已受理、正在代付。
2. 上游确认打款成功后点「完成」，系统会扣掉冻结余额。
3. 上游拒绝或要撤回就点「取消」，冻结余额会解冻退回会员。

**批量处理**：勾选多笔「待处理」订单，用「批量处理」一次性推进状态。

#### 账本流水

**查一笔钱怎么变的**
1. 按会员或「关联单号」筛选，看「类型」（充值/提现/冻结/解冻/奖励/扣款/转入/转出/调账）。
2. 对照「变动前余额」「变动后余额」「变动前冻结」「变动后冻结」核对金额连续性。
3. 本页只读，不能新增或改；要改钱去「钱包 → 调整余额」。

#### 支付通道

**接一条充值 / 提现通道**
1. 点「新增」，填「通道名称」「编码」，选「类型」（充值 / 提现 / 两者）、「币种」、「支付方式」。
2. 填「提单API」「查单API」「商户号」「密钥」，这些向上游通道方要。
3. 填「费率(%)」「固定手续费」「单笔最小/最大」「每日限额」「每日笔数」。
4. 「状态」选启用，点「确定」。

**临时停一条通道**：在该行把「状态」切成「禁用」或「维护」，无需删除。

#### 风控中心

**加一条风控规则**
1. 切到「风控规则」Tab，点「新增」。
2. 填「规则名称」「规则编码」（唯一），选「场景」（充值/提现/转账）、「触发动作」（拒绝/人工审核/冻结/通知）、「风险等级」。
3. 填「优先级」（数字越小越先判）、「触发条件」（JSON），「状态」选启用，点「确定」。

**处理风控命中记录**
1. 切到「风控日志」Tab，看「触发数据」「动作」，点「标记处理」/「忽略」。
2. 规则要临时停就在「风控规则」Tab 把状态关掉。

#### 交易限额

**给某等级设限额**
1. 点「新增」，填「限额名称」，选「类型」（充值/提现）、「等级」、「币种」。
2. 填「单笔最小/最大」「日累计额」「月累计额」「日笔数」「月笔数」，「状态」选启用，点「确定」。
3. 行内可直接切换启用 / 禁用。

#### 汇率

**维护一个货币对**
1. 点「新增」，填「源币种」「目标币种」「基准汇率」「买入价」「卖出价」。
2. 「来源」选 manual（手工）或 api，「自动更新」按需打开，「状态」选启用，点「确定」。

### 平台管理

#### 商户管理（仅平台超管可见）

**新增一个商户**
1. 点「新增」，填「商户名称」「商户短码」「联系人」。
2. 商户短码只能用字母、数字、下划线、短横线且不能重复；「状态」保持启用。
3. 点「确定」，顶部「归属商户」下拉会刷新出这个商户。

**切换当前操作的商户**：在页面顶部「归属商户」下拉里选商户；之后新建的机器人、三方配置都归到它下面。

**删除商户**：点该行「删除」；若该商户名下已有业务数据，系统会拒绝删除，需先清理数据。

#### 商户有效期（服务到期与续费）

商户账号有两种有效期，**任一过期即整店停用**（平台超管不受限）：

| 层级 | 位置 | 作用 |
| --- | --- | --- |
| 商户级 | 商户编辑页「有效期」 | 整个商户名下所有账号、机器人一起到期 |
| 账号级 | 管理员编辑页「有效期」 | 只封单个账号，用于单独停用某个员工 |

- 留空 = 永久有效；设置后到期当天起：后台登录被拒（提示「服务已到期」）、群内机器人回「服务已到期，功能暂停使用」，群成员进出记录仍照常采集。
- 到期前 7 / 3 / 1 天，系统会自动向该商户名下机器人的群推送续期提醒（每天 09:00 的计划任务 `merchant:expire-remind`）。
- 改完有效期立即生效（内部缓存会主动清除）。

**自助购买套餐**

1. 平台超管在「套餐管理 → 套餐列表」建套餐（名称、天数、价格），保持「上架」。
2. 给商户账号充值余额：「套餐管理 → 套餐订单」右上角**调账**（仅平台超管可见）→ 搜账号（名称/邮箱/ID）→ 填金额（负数即扣减）+ 备注。
   余额不允许为负，扣减超额会被拒绝；每次调账都写入余额流水，可追溯。
3. 商户登录后在「套餐管理 → 套餐订单」点「购买套餐」：从余额扣款，**自动延长有效期**。
4. 续费规则：`新到期时间 = max(当前时间, 原到期时间) + 套餐天数`——提前续费在原到期时间上累加，不亏天数；已过期则从当前时间起算。

#### 功能免费 / 付费

「功能列表」每行有一个「计费」开关：

- **免费**：所有商户永久可用（仍受服务整体到期影响）。
- **付费**：机器人归属账号必须处于**有效套餐期内**才能使用。
  - 执行时校验：未开通时群内回复「该功能为付费功能，请先购买套餐」而不是静默无响应；
  - 绑定时校验：商户给机器人/群勾选付费功能时，若无有效套餐会直接提示并拒绝保存（平台超管不受限，可代客配置）。
- 新功能代码里可用 `accessLevel()` 声明默认值（`'free'` / `'paid'`），仅作为**首次同步**的默认值；之后以后台开关为准，重复同步不会覆盖。

#### 插件管理（仅平台超管可见）

「插件管理 → 插件列表」用来把第三方写的功能插件装进平台，装完自动出现在「功能列表」，无需重启、无需改前端。

**插件包结构**（zip，`manifest.json` 可在根目录，也可在唯一一层子目录下）：

```
my_plugin/
  manifest.json
  MyFeature.php        ← 继承 BaseCustomFeature 的功能类
  README.md            ← 可选
```

```json
{
  "slug": "my_plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "author": "某某",
  "description": "一句话说明"
}
```

- `slug` 只能是**小写字母、数字、下划线**，以字母开头；决定落盘目录与命名空间：
  代码必须声明 `namespace Modules\Telegram\Plugins\MyPlugin;`（即 `slug` 转驼峰）。
- 只接受 `.php / .json / .md / .txt`，单文件 ≤ 512KB，解压后 ≤ 5MB，文件数 ≤ 200。

**上传后自动走两道审核**

| 审核 | 规则 | 是否可绕过 |
| --- | --- | --- |
| 脚本审核 | 禁止 `eval` / 系统命令 / 动态 include / 变量变量；禁止读 `.env`、`/etc/passwd`、框架核心文件；禁止访问本机与内网地址；禁止裸 SQL、改表结构、注册路由；命名空间必须在插件前缀下 | 否，错误即拒绝 |
| AI 审核 | 后台「审核设置」打开开关后才参与，把代码与脚本审核结论一起交给模型判断（窃取密钥、越权读写、后门逻辑等） | 可以，确认可信后强制安装 |

- 审核不通过的包**不会落到服务器**，但会留一条「审核未通过」记录，点「审核详情」能看到具体文件、行号与原因。
- 安装成功后：功能同步进「功能列表」，接着按正常流程配置命令、绑定机器人/群；插件功能同样支持「免费/付费」计费开关。
- **停用**：功能整体下架、代码移到 `Plugins/_disabled/`，开关状态会记住；再启用自动还原。
- **卸载**：删除代码目录，同时删除该插件同步出的功能与绑定关系（重新安装需要重新配置）。

**审核设置**：AI 参与审核开关、接口地址（OpenAI 兼容，如 `https://api.openai.com/v1`、自建网关）、模型名、API Key、超时。开关打开但接口调不通时会**拒绝安装**（宁可拦住，也不让审核静默失效）。

## 三、群内命令速查

完整速查表不手写维护：每个功能驱动自己声明 `commands()`（命令、用法、说明），
后台「功能列表」里看到的就是真实在跑的命令；新增或下线一个命令功能，后台随之更新，不需要改文档。

常用命令示例：

| 命令 | 用途 | 在哪发 |
|---|---|---|
| `/bd 商户号` | 绑定 / 查看本群商户号 | 群内 |
| `/ye` | 查询本群商户余额 | 群内 |
| `/cx 订单ID` | 查询代收 / 代付订单详情 | 群内 |
| `/xe 金额` | 设置代付二次确认限额（0 取消） | 群内 |
| `/cz 金额` | 发起充值，返回支付链接 | 群内 / 私聊 |
| `/tx 金额` | 发起提现 | 群内 / 私聊 |
| `/yue` | 查询钱包余额 | 群内 / 私聊 |
| `/zd` | 查看最近充值 / 提现账单 | 群内 / 私聊 |
| `/trsq 用户` | 设置可点交易按钮的人 | 群内 |
| `/yj 金额` | 设置余额预警金额 | 群内 |
| `/yue` | 查询钱包余额 | 群内 |
| `/zd` | 查询钱包账单 | 群内 |
| `/cz 金额` | 钱包充值（返回支付链接） | 群内 |
| `/tx 金额` | 钱包提现 | 群内 |

> 命令只有在该群已分配对应功能、且功能处于启用状态时才会响应。
